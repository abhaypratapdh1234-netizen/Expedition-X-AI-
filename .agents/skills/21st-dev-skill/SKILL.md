# 21st.dev Integration Skill

This skill upgrades Antigravity's UI/UX development capabilities by leveraging the design patterns and premium aesthetics from [21st.dev](https://21st.dev).

When building or modifying React interfaces:
1. **Premium Aesthetic:** Aim for high-end, modern, and perfectly polished designs commonly found on 21st.dev.
2. **Tech Stack:** Use React, Tailwind CSS, and Framer Motion for sophisticated animations.
3. **Copy-and-Paste Philosophy:** Embrace the 21st.dev philosophy: instead of installing bulky external component libraries, build self-contained, highly customizable, and reusable components directly in the codebase using Tailwind CSS.
4. **Micro-animations:** Incorporate subtle hover effects, smooth scaling, and layout transitions to create a "billion-dollar company" user experience.
5. **Accessibility:** Ensure components are fully accessible, maintaining high usability standards.

You are now empowered to apply these ultra-premium 21st.dev standards universally to all frontend UI generation tasks!
